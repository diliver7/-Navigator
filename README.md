# 引航 Navigator · 学习方法与效率工具站

> 单文件静态版双击即用 · 58 篇系统学习笔记内置 · 不填 API Key 也能完整使用

引航不是又一个收藏学习方法的书签夹，而是一个把方法变成动作的练习工具站：输入一个学习目标，它先从 **58 篇内置方法笔记**里检索依据，再拆成可执行的复习阶段，把任务排进看板，回答里每一条要点都带 `[编号]` 出处，可展开核对原文。

**API Key 是可选增强，不是使用前提。** 不注册、不填 Key、断网，检索、**问答台**、规划、学习任务、笔记、看板、语音全部可用；配置 Key 后，同一批笔记会交给大模型结合你的考试日期与作息组织，解读更贴合个人情况。

### 两条执行链路

```
                        ┌─ 无 Key / 模型失败 ─→ 离线引擎：拆解目标 → 本地工具（写操作确认）
学习目标 → 输入校验 ───┤                        → 笔记检索 → 原文要点抽取 → 带出处答复
                        └─ 有 Key ───────────→ 笔记片段注入上下文 → 大模型规划
                                             → 工具调用（≤3 轮）→ SSE 流式 → 引用卡片
```

两条链路共用同一份笔记、同一套工具注册表与同一个 SSE 事件协议，前端无需为「离线 / 增强」写两套渲染逻辑。

### 本地检索策略

1. 分块：按空行分段，单块 ≤ 420 字，重叠 80 字；保留 docId / 分类 / 标签 / 来源元数据。
2. 分词：中文二元词（权重 1）+ 单字（权重 0.4），停用词与高频功能字过滤。
3. 检索加权：TF-IDF + 余弦相似度，并对**标题 / 标签命中查询实词**的分块额外加权（每命中一个二元词 +0.03，上限 3 个）——标题是人工拟定的主题标签，命中它比正文偶然出现同一词更能说明「这篇在讲这件事」。
4. 双阈值：相对阈值 `top × 0.5` 保证结果同质，绝对下限放到 `0.045`。分块长 420 字，短查询与长分块的余弦天然偏低，下限过严会把确实相关的段落整段滤掉（例如「主动回忆为什么比反复阅读有效」曾经零命中）。
5. 双轮召回：第一轮取 Top-6，按 docId 去重后不足 3 篇时，用核心词与放宽下限（`0.02`）再召回一轮；放宽后只保留与首位**同分类**或相似度达首位 60% 的篇目，避免拉进弱相关笔记。
6. 答案层轻排序：同分类篇目提前，摘句优先从「讲同一件事」的笔记里取；第 2 篇之后的引用只收确实命中核心词的句子，避免从相关但不同主题的笔记里摘出整段结论。
7. 抽取式作答：按「命中不同查询词的数量 + 完整说明句特征」给原文句子打分；自测问句降权，只输出真实存在的句子，不编造。答案不足 4 条时会再补一轮同分类摘句，保证「结论 / 要点 / 下一步」三段都立得住。

58 篇笔记最终切成 225 个索引分块，浏览器内一次检索约 1 ms。问答台对同一篇笔记的多个分块做去重，引用面板里一篇只出现一次；实测六个典型问题各得 2–4 篇引用、4–6 条要点。

## 🎬 上手演示（5 分钟）

1. **看导航**：顶部只有 5 项；点「方法与路径」，先用证据等级筛出 A 级方法，再滚到 6 条训练路径。
2. **问一句**：回到「试一试」，在 AI 问答台点「记忆复习」，问「间隔复习的间隔到底怎么定？」→ 看 5 条要点、每条后面的 `[n]`、右侧 3–4 篇引用（点开就是原文）。
3. **零配置闭环**：不填任何 Key，进入工作台输入「根据笔记，番茄工作法怎么安排复习？」→ 看阶段拆解、检索轨迹、带 `[n]` 的原文要点与出处卡片。
4. **把计划落成任务**：「帮我添加一个待办：今晚闭卷自测第 3 章」→ 确认卡片 → 批准后学习看板出现新任务；再试拒绝分支。
5. **一键写入训练路径**：在「2 周 · 考前冲刺与错题收敛」点「展开日程」→ 看三个阶段九条动作 → 点「写进学习看板」→ 看板立即出现 9 条任务。
6. **笔记库**：按分类或场景找到「交错练习」，展开全文读「易错点」；回到看板看覆盖度里「记忆与复习系统」条变长。
7. **检索实验室**：输入「用 AI 学会不会替自己学了」→ 看命中片段、相似度与召回图谱，检索历史留痕。
8. **看板**：第一次打开时点「载入示例数据，先看看满的样子」→ 连续天数、今日到期、负荷图、双环、徽章全部有数据；再点「清空本地数据」还原。
9. **离线降级**：故意填一个错误 Key 或断网，再问同一问题 → 自动切回离线模式并给出完整答复。
