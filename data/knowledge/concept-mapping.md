# 概念图与矩阵表：把关系画出来，而不是把字抄一遍

- 分类：笔记与阅读
- 标签：概念图 / 矩阵表 / 关系词 / 效应量 / 结构化笔记
- 来源：Fiorella & Mayer (2015) · 概念图 d = 0.62（23/25 项比较为正）、矩阵组织图 d = 1.07、知识地图 d = 0.43；Wittrock (1989) · 生成学习理论：选择—组织—整合；Novak & Cañas · 概念图方法（命题式节点—连线结构）

---

【核心概念】概念图不是好看的分支树，而是由「节点—带关系词的连线—命题」构成的网络：两个节点加一条写清关系的连线，就形成一条可检验的命题。矩阵表则是把若干对象按同一组维度横向排开，强迫你补齐空白格。两者都属于生成式学习中的空间型策略，Fiorella 与 Mayer 汇总的中位效应量分别为 d = 0.62 与 d = 1.07（后者研究数较少，宜谨慎），明显高于单纯划线或重读。

【关键结论】第一，价值来自「取舍 + 关系化」：你必须决定哪些概念值得进图、它们之间是因果、包含、条件还是对立，这一步就是选择与组织。第二，关系词是概念图的灵魂，没有「导致 / 属于 / 区别于 / 依赖于」这类标注，图退化成装饰性词云。第三，矩阵表的威力在空格：当你把「方法 / 适用目标 / 证据强度 / 常见误用」列成表，任何填不出的格子就是理解缺口。第四，概念图对低先验知识者帮助最大，但需要示范与训练，否则容易画成抄书。第五，图应该能被用于自测：盖住关系词或盖住半个节点，尝试复原，才形成提取练习。

【操作步骤与示例】第一步，从一节里挑出 5–8 个核心概念写成卡片。第二步，两两问「它们之间是什么关系」，能答出就画一条带关系词的连线，答不出先标记为空。第三步，把成组概念横向排成矩阵，维度固定为「定义 / 适用条件 / 反例 / 出处」，逐格填写。第四步，24 小时后盖住图重画一次，用红笔标出复原失败的部分。第五步，把红笔部分改写成自测卡。举例：学「认知负荷」时把内在负荷、外在负荷、工作记忆、图式、样例效应作为节点，连线写「占用」「被……缓解」「经……自动化」，再列一张三行矩阵比较三类负荷的定义、可改变性与课堂例子。

【易错点】第一，把概念图做成彩色分支树，只有层级没有命题。第二，节点过多（十几二十个）导致图本身成为新的认知负荷。第三，边看材料边抄图，没有闭卷提取，产出质量虚高。第四，把 d = 1.07 当成矩阵表普遍有效的保证，忽略它来自少量比较。第五，画完即存档，从不复画、从不用它出题。

【自测题】概念图中一条「命题」由什么构成？矩阵表为什么能暴露理解缺口？怎样把概念图变成提取练习？答案要点：两个节点加一条写明关系的连线；空格迫使你为每个对象补齐同一组维度，填不出即缺口；隔天盖住图重画或用红笔补关系词，再把错误处改写成自测卡。
