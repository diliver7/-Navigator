# 八种生成式学习策略：把「读过」变成「产出」

- 分类：学习科学基础
- 标签：生成式学习 / 效应量 / ICAP / Fiorella & Mayer / 主动输出
- 来源：Fiorella & Mayer (2015) · Eight Ways to Promote Generative Learning（八种策略中位效应量汇总表）；Wittrock (1989) · 生成学习理论：选择—组织—整合；Chi & Wylie (2014) · ICAP 框架：被动 < 主动 < 建构 < 交互

---

【核心概念】生成式学习指的是学习时主动产出某种外在或内在的表征，而不是重复接收原文。Fiorella 与 Mayer 汇总了八种策略及其对照实验中位效应量：写摘要 d = 0.50、画概念图 d = 0.62、画矩阵表 d = 1.07、画图 d = 0.40、在脑中想象 d = 0.65、自测 d = 0.57、自我解释 d = 0.61、讲给别人听 d = 0.77、动手演练 d = 0.51。按 Hattie (2011) 的标准，d ≥ 0.4 已属有教育意义。前四种是「把文字换成另一种表征」，后四种是「在原有材料上再生成答案或解释」，共同机制是 Wittrock 说的三步：选择关键信息、组织成结构、与旧知识整合。

【关键结论】第一，效果取决于「产出的质量」而不是「有没有做动作」——潦草抄一遍原文的摘要不属于生成。第二，策略要匹配材料：言语型（摘要、自测、自我解释、讲授）适合非高度空间化的材料；空间型（构图、画图、想象、演练）适合复杂或带空间关系的 STEM 内容。第三，低先验知识、低技能的学习者受益最大，高水平学习者往往已经自发在做这些事，边际收益变小；但低水平者恰恰需要明确指导才会用。第四，ICAP 框架给出排序：被动听 < 主动划线 < 建构产出 < 交互辩论，划线之所以常被判低效用，是因为它停在「主动」层。第五，「讲给别人听」的中位 d 最高（0.77），但样本量最小，宜当作有前景的补充而非定论。

【操作步骤与示例】读完一节后按固定顺序做三件事：合上材料选三条最关键的结论（选择）；把它们画成一张关系图或填进「概念 / 定义 / 例子 / 反例」四列矩阵（组织）；写一句「这和我已知的 X 有什么相同与不同」（整合）。然后闭卷自测，再用自己的话讲给同学或对着手机录音讲两分钟。举例：学「认知负荷」时，画一张「内在负荷—外在负荷—工作记忆容量」的三框关系图，写一句「它和番茄钟都在管有限资源，但一个管材料设计、一个管时间结构」，再闭卷写出三类负荷的定义各一条。整个流程约 15 分钟，远少于重读三遍的时间。

【易错点】第一，把「生成」做成装饰——画了彩色思维导图但没有任何关系箭头与取舍。第二，材料本身高度空间化时仍只用言语摘要，丢了双通道优势。第三，给新手一堆策略却不示范，产出质量低反而增加负荷。第四，把中位效应量当作对每个人都成立的保证值，忽略先验知识的调节。第五，一次叠用八种策略，时间全花在形式切换上。

【自测题】生成式学习的三个认知步骤是什么？为什么低先验知识者受益更大却更需要指导？材料是复杂空间结构时应选哪一类策略？答案要点：选择、组织、整合；他们原本缺少自发策略与背景图式，但独立产出的质量往往不足；选空间型策略，如构图、画图、想象或动手演练。
