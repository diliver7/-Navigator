# 自己画图与 ICAP：被动、主动、建构、交互的四级差

- 分类：笔记与阅读
- 标签：自绘图示 / ICAP / 绘画效应 / 认知参与 / Wammes
- 来源：Wammes et al. (2016) · 绘画比书写更利于记忆的系列实验；Fiorella & Mayer (2015) · 画图 d = 0.40（26/28）、心理想象 d = 0.65（16/22）；Chi & Wylie (2014) · ICAP 框架：Passive < Active < Constructive < Interactive；Schmidgall · Drawing to Learn 研究：生成、可视化、外化三因素分解

---

【核心概念】ICAP 框架按可观察的学习行为把认知参与分四级：被动（只听只读）、主动（划线、复述、抄写）、建构（用自己的话产出超出原材料的内容，如画图、写解释、做概念图）、交互（与同伴就内容进行有来回的建构性讨论）。预测的学习成效依次递增。学习者自绘图示之所以有效，是同时叠加了三个因素：生成（自己决定画什么）、可视化（转成图像编码）、外化（把内部表征放到纸上可反复检视）；Schmidgall 的研究发现，当策略执行质量高时，画图组优于写自我解释组。

【关键结论】第一，「动笔」不等于「建构」——照抄板书停在主动层，把文字转成一张关系草图才进入建构层。第二，画图的中位效应量约 d = 0.40，心理想象约 d = 0.65，但都高度依赖产出质量；画得潦草、与材料无关时几乎无益。第三，画图对复杂或空间化材料（机制流程、几何结构、生理过程）尤其合适；纯言语事实材料用自测或摘要更省时。第四，交互层的增效来自「彼此质疑并修正」，不是坐在一起各画各的。第五，画得美不美不重要，图中是否包含正确的关系与关键节点才重要，研究里并不要求绘画技能。

【操作步骤与示例】读完一段机制描述后，限时 5 分钟在草稿纸上画一张「能讲清过程」的简图：只画方框、箭头与关系词，不涂色不修饰。画完立刻做两件事：在图上标出「我最不确定的一步」，以及写一句「如果这里反过来会怎样」。然后与同伴互相讲图、互相挑错，把争议点记成自测卡。举例：学「睡眠巩固记忆」时画「编码 → 夜间 NREM 慢波 → 再激活 → 稳定性提高」四框流程，在 NREM 那一步旁打问号，回头查笔记确认后补上来源；下次复习时只看图闭卷复述整条链。

【易错点】第一，把时间花在配色与排版上，把建构任务降级为美工任务。第二，照着教材插图临摹，没有自己决定取舍，等于主动层。第三，画的是装饰性场景而非关系结构。第四，不给图配关系词与问号，事后无法用它自测。第五，误以为「画得丑就没用」，因自我评判而放弃这个高效动作。

【自测题】ICAP 四级分别对应哪些典型行为？画图有效的三个因素是什么？为什么临摹教材插图收益有限？答案要点：被动听讲、主动划线复述、建构产出解释或图示、交互质疑讨论；生成、可视化、外化；临摹缺少自主取舍与整合，认知参与停在主动层，未形成超出原材料的新表征。
