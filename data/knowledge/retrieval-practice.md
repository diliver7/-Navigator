# 主动回忆：把「看过了」变成「答得出」

- 分类：学习科学基础
- 标签：主动回忆 / 测试效应 / 检索练习 / 闭卷自测 / 反馈
- 来源：Roediger & Karpicke (2006). Test-enhanced learning: Taking memory tests improves long-term retention. Psychological Science, 17(3), 249-255；Karpicke & Blunt (2011). Retrieval practice produces more learning than elaborative study with concept mapping. Science, 331, 772-775；Rowland (2014). The effect of testing versus restudy on retention: A meta-analytic review. Psychological Bulletin

---

【核心概念】主动回忆指合上材料后，主动从记忆中提取信息并输出，例如闭卷默写要点、做练习题、向别人复述、用卡片自问自答。它之所以有效，是因为提取这个动作本身会加固记忆痕迹并增加未来的提取线索，这被称为测试效应或检索练习效应；与之相对的是重读与划线，它们只需识别眼前的信息，几乎不要求从记忆中取回任何东西。

【关键结论】第一，Roediger 与 Karpicke 在 2006 年的经典实验中让学生学习短文，一组反复重读，另一组把同样的时间用于自由回忆，五分钟后的即时测验里重读组略占优势，但一周后的延迟测验完全反转，回忆组记住的内容显著更多，常见引述的量级约为 61% 对 40%。第二，当时重读组对自己一周后表现的预测反而更乐观，说明主观信心与客观留存可以背道而驰。第三，Karpicke 与 Blunt 在 2011 年发表于《Science》的研究进一步发现，检索练习在需要推理迁移的题目上也优于边看材料边画概念图，因此它不只是死记硬背的技巧。第四，Rowland 2014 年的元分析确认测试相对重读存在稳定的总体优势，但效应大小会随材料与反馈条件变化。第五，反馈是关键放大器，答完立刻或稍后核对正误，能纠正错误并避免把错误选项记成正确知识。

【操作步骤与示例】第一步，学完一小节后立刻合上书，用白纸写出这一节的标题、三条核心结论与一个例子，写不出来的地方留空。第二步，翻开原文只核对留空与写错的部分，用另一种颜色补齐，并给错漏处写一句「为什么会错」。第三步，把错漏改写成问题卡片，例如「测试效应在即时与延迟测验上的差别是什么」，排进第 1 天、第 3 天、第 7 天各测一次。第四步，每次自测严格限时且不翻书，测完统一核对，把反复错的题升级为需要重新理解的知识缺口。举例来说，复习一章心理学时不要划满荧光笔，而是先花八分钟闭卷写出四种学习法的评级与依据，再回书补漏，最后把三条错漏做成卡片。

【易错点】第一，边看边抄误当成回忆，只要眼睛还停在原文上，提取就没有真正发生。第二，只看答案不先作答，卡片翻面太快会退化为识别而非回忆。第三，没有反馈，答错后不核对会把错误固化下来，Butler 与 Roediger 2008 年的研究显示反馈能明显减少后续重复错误。第四，题目只考原句复述，长期只做同一层级的题会限制迁移，应逐步加入需要解释、应用与比较的题目。第五，一上来就用高难度检索把新手卡死，此时应回到《样例学习》先搭起基础图式。

【自测题】为什么即时测验与延迟测验会给出相反结论？测试效应是否只适用于背诵事实类知识？一次完整的主动回忆循环最少包含哪三个环节？答案要点：重读带来短期熟悉但 decay 快，检索加固长期痕迹与提取路径；不是，Karpicke 与 Blunt 显示在推理迁移题上同样占优；闭卷输出、核对反馈、把错漏排进后续复习。
